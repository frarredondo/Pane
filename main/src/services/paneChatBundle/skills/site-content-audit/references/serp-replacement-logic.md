# SERP replacement logic

Before diagnosing a content decline, find out whether the traffic disappeared
or moved.

## Process

1. Select the important lost queries.
2. Check the current top results.
3. Classify the replacements:
   - direct competitors
   - independent review sites
   - forums and community results
   - official docs
   - media and publishers
   - SERP features or AI answers
4. Compare each replacement page with the lost page on:
   - answer set
   - criteria
   - firsthand proof
   - product promotion
   - freshness
   - time to value
   - page type
5. Decide whether demand likely shrank, rankings transferred, or both.

## Unsupported conclusions

Test each of these against the evidence before stating it:

- "AI killed it" needs query-level evidence.
- "Google punished topical overreach" fails when direct product-category
  queries also died.
- "Backlinks caused it" fails when links improved, or when competitors with
  similar junk links still rank.
- "Domain authority is enough" fails when lower-authority pages replaced the
  site.

## Output

For each query or cluster:

- Former page
- Current winners
- Replacement type
- What the winners satisfy better
- What evidence is missing
- Implication for rewrite, prune, or recovery
